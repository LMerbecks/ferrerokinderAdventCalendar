# Ferror kinder advent calendar
This repository contains code that creates a [ferrero
kinder](https://kinder.com) advent calendar.

This repository is not at all involved with ferrero and only provides
information on a DIY advent calendar. 

## Motivation

The problem with the official ferrero advent calendar is that it does not cover
the entire product inventory and also has to omit all refrigerated products. 

The goal of this project is to provide an advent calendar that vocers almost
the entire product inventory (or as much as possible) within specified
contraints. Because this DIY uses an empty calendar (like e.g.
[this](https://papierdrachen.de/product/adventskalender-weihnachtsdorf-bunt/?gad_source=1&gad_campaignid=23017425051))

Furthermore, in this project the products can be combined with weights. 

## Goal 

The first version should maximize product coverage while keeping the number of
items in each bin constrained. More information on the [problem description](doc/problemDescription.md).
